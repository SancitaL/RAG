# EvidenceRAG 需求说明
PyMuPDF == Version 2.0

## 项目概述

EvidenceRAG 是一个中文优先的企业知识库问答系统。用户导入知识文档后，以自然语言提问。系统从用户有权访问的文档片段中检索证据，基于证据生成带来源引用的答案；证据不足时明确拒答，不编造答案。

项目周期为 40 天，按每天 6 小时、总计约 240 小时规划。目标是交付可本地启动和演示的工程作品，并用固定公开数据集评测检索与回答表现，不承诺预设分数。

## 用户与主要场景

- **知识库使用者**：询问内部知识、流程、政策或产品资料，并核对答案依据。
- **知识库维护者**：导入或更新文档，检查解析结果及来源元数据。
- **项目评测者/开发者**：运行固定评测集，比较检索策略、查看失败案例和运行指标。

核心流程：维护者导入 Markdown、HTML 或 PDF；系统解析、清洗、切分并保存文档元数据；使用者提交问题和过滤条件；系统执行受权限约束的检索并生成答案；回答附来源，资料不足时拒答；开发者运行评测并检查结果。

## 功能需求

### 文档处理

- 支持 Markdown、HTML、PDF 的导入、解析、清洗和切分。
- 保留文档 ID、片段 ID、标题、来源、语言及可用的页码、URL、部门、文档类型、日期和权限标签。
- 处理过程可重复执行；原始数据、处理后数据和代码分开管理。

### 检索与问答

- 使用 PostgreSQL + pgvector 提供向量检索，并实现 BM25、混合检索及 cross-encoder reranking。
- 支持 top-k 和部门、文档类型、日期、权限标签等元数据过滤。
- 基于检索证据生成中文答案，引用可追溯到具体文档和片段。
- 证据不足时拒答；检索到的文档内容不得被当作可信指令。
- 查询改写、多查询或问题拆分属于可选策略，需确保核心链路和时间后再纳入。

### 评测、服务与演示

- 使用 MIRACL 中文版作为主检索公开数据，抽取约 100–300 条标注查询及相关/干扰文档；记录来源、许可、版本、抽样方式和校验信息。
- 使用少量 HotpotQA 样本作为多跳问答进阶评测；保留来源和 CC BY-SA 4.0 许可信息。
- 提供固定评测数据和脚本，逐步覆盖 Recall@k、MRR、nDCG、答案正确性、忠实度、上下文相关性、引用质量、拒答表现、延迟和成本。指标按实际结果报告。
- 提供 FastAPI 接口、简单问答页面和 Docker Compose 开发环境。
- 记录请求、检索/生成耗时、token 用量、估算调用成本和错误。

## 非功能要求

- **可解释**：能检查检索片段、来源及主要实验配置。
- **可复现**：公开数据处理、评测和运行步骤有说明；固定评测集冻结后不随意修改。
- **权限边界**：在检索阶段实施权限/元数据过滤，并演示越权查询不会返回受限内容。
- **容错**：对空结果、无效输入、超时和模型服务错误有明确处理。
- **范围控制**：优先端到端主链路、评测、服务化和演示；Self-RAG、CRAG、GraphRAG、ColBERT、Agentic RAG 和微调仅做有限实验或设计分析。

## 项目边界与假设

- 面向本地开发和演示，不承诺生产级可用性、完整企业 SSO、多租户隔离、海量并发或正式合规认证。
- 中文检索和问答是主线；MIRACL 全量约 490 万篇语料不在 40 天内处理，只使用受控子集。
- 不把未经许可核查的数据作为可自由分发的数据；若许可不适合重新分发，提供获取/处理脚本和说明，不提交原始数据。
- 模型、Embedding、reranker 与解析库根据环境在计划阶段选定；确定主线后避免迁移多个框架或向量数据库。
- 引用、拒答和评测用于降低错误风险，不声称完全消除模型错误。

## 验收标准

1. 按文档说明启动 Docker Compose，并通过 API 或问答页面完成演示。
2. 导入 Markdown、HTML、PDF 文档，并查看带来源元数据的解析片段。
3. 展示向量、BM25、混合检索和 reranker 的结果比较。
4. 对可回答问题生成带可核对出处的答案，对证据不足问题拒答。
5. 演示元数据/权限过滤，证明受限内容不会进入检索结果。
6. 根据公开数据来源说明准备评测集，并可重复运行评测脚本。
7. 提供真实评测结果、失败案例、架构与运行说明、限制和面试讲解材料。

## Day 1 决策记录

- 项目名称与主线：EvidenceRAG，中文优先、带证据引用和拒答的企业知识库问答。
- 核心存储/向量检索：PostgreSQL + pgvector；不在本项目内并行引入其他向量数据库。
- 主要公开检索数据：MIRACL 中文版；HotpotQA 为小规模进阶样本。
- 详细库、模型和部署参数留待相应阶段结合环境确定。
