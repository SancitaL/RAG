# EvidenceRAG

EvidenceRAG 是一个面向企业知识库问答的中文 RAG 工程项目。用户导入知识文档后，可以用自然语言提问；系统检索相关证据，生成带出处的回答，并在资料不足时明确拒答。项目同时提供固定公开数据集、可重复评测和实验记录。

## 项目目标

在 40 天、约 240 小时内交付一个可运行、可解释、可测量、可演示的作品。核心范围包括文档处理、PostgreSQL + pgvector 向量检索、BM25 与混合检索、reranker、证据引用与拒答、权限过滤、评测、FastAPI、Docker Compose 和简单问答界面。高级方法以有限实验或设计说明为主。
